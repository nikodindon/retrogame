# Politique de confidentialité — RetroGame

## Données collectées
- **Aucune donnée personnelle** n'est collectée par l'application elle-même.
- Le meilleur score et les préférences (son, vibration) sont stockés localement via `SharedPreferences` sur l'appareil.
- Aucune inscription, aucun compte utilisateur n'est requis.

## Publicité (AdMob)
- L'application utilise le SDK Google AdMob en mode développement avec des identifiants de test (`ca-app-pub-...`).
- Aucune donnée personnelle n'est partagée avec des tiers au-delà des mécanismes standard du SDK AdMob (identifiant publicitaire de l'appareil, si le consentement est accordé).
- Le consentement publicitaire est respecté conformément au RGPD et aux règles Google Play.

## Achats (Google Play Billing)
- Les achats et abonnements sont gérés par Google Play Billing ; aucune information de paiement n'est stockée par RetroGame.

## Sécurité
- L'application ne nécessite que la permission `INTERNET` (pour AdMob et Play Billing).
- Aucune clé secrète ou token n'est inclus dans le dépôt public.

## Contact
Pour toute question : contact via le dépôt GitHub `https://github.com/nikodindon/retrogame`.
